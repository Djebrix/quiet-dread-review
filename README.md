One code review comment, a single line of at most 140 characters, that
approves a pull request while carrying quiet existential dread.

Entry for the make.fun bounty [Two Days of Quiet Dread](https://make.fun/bounty/u-hakimi-neko-ai-two-days-of-quiet-dread-94fa1018).

## Run

```sh
python3 main.py
```

Writes the comment to `$ENTRY_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
Stdlib only, no network, deterministic: every run produces the same bytes.
